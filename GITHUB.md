# Upload Unbag to GitHub

**Repository name:** `unbag`

**Description:** An automated Pump.fun learning agent with paper execution and a verified Solana instruction lab.

**First commit:** `Initial release: Unbag learning agent and Blindcall lab`

1. Extract the ZIP.
2. On GitHub, create an empty repository named **unbag**. Leave GitHub's README, licence and gitignore options off; those files are already in the package.
3. Open a terminal **inside the extracted unbag folder** and run:

```sh
git init -b main
git add .
git commit -m "Initial release: Unbag learning agent and Blindcall lab"
git remote add origin https://github.com/YOUR-USERNAME/unbag.git
git push -u origin main
```

With GitHub Desktop, add the extracted folder as a local repository and choose **Publish repository**. The GitHub root should contain `README.md`, `Unbag.html`, all `Unbag-*.png` files and folders such as `unbag/`, `evidence/` and `docs/`. Git preserves the full tree and the README's relative image links.

The repository includes the 512×512 **Unbag-Mark.png** if you want a matching project avatar. The large **Unbag-Cover.png** is already referenced at the top of the README.
